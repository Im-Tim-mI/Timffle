# net5 — 第 5 組：flash.net NetStream、NetGroup／GroupSpecifier／NetGroupInfo、flash.net.drm

批次名稱 `net5`。分支 `worktree-agent-a34bdd9e0fafa576c`（自 PRO_bata 244a861a）。

## (a) CHANGELOG 條目

- **第 5 組（網路／媒體／DRM）：`flash.net.NetStream` 4 缺 + 50 空殼、`NetStreamInfo.toString`／`NetStreamMulticastInfo.toString` 空殼、`NetGroup` 21 缺、`NetGroupInfo`（新類別，9 缺）、`GroupSpecifier`（新類別，22 缺）、`flash.net.drm` "client-inBufferSeek"`，**資料產生模式**（`play(null)` + `appendBytes`／`appendBytesAction`）真的把位元組餵進 FLV 解析器（`RESET_BEGIN`／`RESET_SEEK`／`END_SEQUENCE` 都照文件），建構子與 `attach()` 照 Flash 要求已連線的 NetConnection（null `close()`）、`onPeerConnect()` 預設回 true。`GroupSpecifier` 整個是真的資料類別（旗標、bootstrap peer、IP multicast 位址驗證、密碼 SHA-256、`makeUnique` 的 16 個強隨機位元組、`G:` + 十六進位選項的字串版面，`new GroupSpecifier("test")` 與 Flash 一樣得到 `G:0101010c050e74657374`）；`NetGroup` 建構子照參考文件在不是 RTMFP 的連線上丟 `ArgumentError #2126`、其餘成員以「未連線的群組」回答；`NetGroupInfo` 全 0 + `toString`。`flash.net.drm` 照沒有 Adobe Access 模組的 Flash：`DRMManager.isSupported` ## (b) CHANGES-FROM-RUFFLE 段落

### 第 5 組：NetStream、RTMFP 群組與 DRM（flash.net.NetStream、NetStreamInfo、NetStreamMulticastInfo、NetGroup、NetGroupInfo、GroupSpecifier、flash.net.drm.*）

- **參考值來自 Adobe AS3 參考文件**（這一批沒有 Wine／真 Flash 可用）：每個成員的預設值、錯誤類別與錯誤碼、事件都取自 airsdk.dev 的類別頁與 runtime error 清單；文件沒寫的部分在各類別的註解與下面的差異表裡標明。測試 `avm2/netstream_members`（FLV 用上游 `netstream_play_stop_replay` 的 `test.flv`）、`avm2/netgroup_groupspecifier_members`、`avm2/drm_members`。
- **`NetStream`**（`NetStream.as`、`net_stream.rs`、`core/src/streams.rs`）：
  - 真的實作（FLV 漸進下載）：`audioCodec`／`videoCodec`（第一個音訊／視訊 tag 的 FLV 編碼器 id，之前是 0）、`decodedFrames`（解碼成功的影格數）、`currentFPS`（最近一秒串流時間內解碼的張數；暫停／關閉時 0）、`bufferLength`（播放位置之後最後一個 tag 的時間戳減目前時間）、`backBufferLength`（`inBufferSeek` 為 true 時播放位置之前的秒數，上限 `backBufferTime`；false 時 0）、`bufferTime`（預設 0.1；負數／NaN 存成 0；**真的擋住開播**：緩衝秒數不到且下載未完成時 tick 不處理 tag，達到或下載完才送 `NetStream.Buffer.Full` 並開始——上游是每個下載區塊都送一次 `Buffer.Full`；斷流 `Buffer.Empty` 之後再次等緩衝並再送一次 `Buffer.Full`）、`backBufferTime`（預設 30，桌面版的值）、`inBufferSeek`（true 時 `NetStream.Seek.Notify` 帶 `description "client-inBufferSeek"`）、`info`（`NetStreamInfo`：`byteCount` = `bytesLoaded`、`audioByteCount`／`videoByteCount`／`dataByteCount` 與三種 `BufferByteLength`／`BufferLength` 由掃描 FLV tag 算出，`currentBytesPerSecond`／`maxBytesPerSecond`／`playbackBytesPerSecond` 每一秒播放器時間取樣一次，各類 `BytesPerSecond` 依位元組比例分配，`droppedFrames` 是解碼失敗的張數，`metaData`／`xmpData` 是最近交給 client 的 `onMetaData`／`onXMPData` 物件，`resourceName` 是解析後的完整網址，`uri` null、`isLive` false（文件：漸進下載如此），`SRTT`／loss rate 0）、`soundTransform`（存在串流上，開始每段聲音時套用，設定時立刻套到正在播的聲音；null 是 `#2007`）、`close()`（停播、停聲音、丟掉緩衝與網址、時間歸 0、留住畫面）、`dispose()`（`close()` 加清掉畫面與尺寸）、`step(frames)`（需要 `inBufferSeek`；正數往前逐張解碼、負數先往回找第 n 張視訊 tag 再從前一個關鍵影格解到那張；目標不在緩衝區就什麼都不做；成功送 `NetStream.Step.Notify`）、`appendBytes`／`appendBytesAction`（`play(null)` 進入資料產生模式：`bytesTotal` 跟著 `bytesLoaded`、`RESET_BEGIN` 清空並等新檔頭、`RESET_SEEK` 清空但保留串流型態／解碼器並以下一個 tag 的時間戳重設時間、`END_SEQUENCE` 標記結束讓串流以 `Play.Stop` 收尾；不在該模式時不做事）、建構子／`attach()` 的檢查（null `TypeError #2007`、未連線 `ArgumentError #2126`）、`onPeerConnect(subscriber)` 宣告成 Flash 的 client 回呼、預設回 true。
  - 照「沒有 FMS／RTMFP」的 Flash：`audioReliable`／`videoReliable`／`dataReliable` getter 永遠 true、setter 忽略；`audioSampleAccess`／`videoSampleAccess`／`checkPolicyFile`／`useHardwareDecoder`（預設 true）／`bufferTimeMax`（0）／`maxPauseBufferTime`／`videoStreamSettings`（null）存放；`useJitterBuffer` 在 `bufferTime > 0` 時 getter 回 false（文件）；`liveDelay` 0；`objectEncoding`／`farID`／`farNonce`／`nearNonce` 轉問 NetConnection；`peerStreams` `[]`；`multicastAvailabilitySendToAll` false、`multicastAvailabilityUpdatePeriod` 0.1、`multicastFetchPeriod` 2.5、`multicastPushNeighborLimit` 4、`multicastRelayMarginDuration` 2、`multicastWindowDuration` 8（RTMFP 實作鏡射 Flash 的預設值）；`multicastInfo` 全 0 的 `NetStreamMulticastInfo`；`publish()`／`send()`／`receiveAudio()`／`receiveVideo()`／`receiveVideoFPS()` 沒有伺服器（`send` 的 null 名稱 `#2007`）；`attachAudio`／`attachCamera` 只可能收到 null（這裡沒有裝置）；`play2()` null `#2007`、`stop` 轉場 = `close()`、其餘 = `play(streamName)`（+`seek(start)`）；`resetDRMVouchers()`／`setDRMAuthenticationCredentials()`／`preloadEmbeddedData()` 沒有 DRM 模組、沒有憑證可刪。
- **`NetStreamInfo.toString()`／`NetStreamMulticastInfo.toString()`／`NetGroupInfo.toString()`**：`name=value` 以空格相連、照 playerglobal 的宣告順序；`NetStreamMulticastInfo` 與 `NetGroupInfo` 的欄位初始為 0（原本 Number 欄位是 NaN）。
- **`GroupSpecifier`**（新檔 `GroupSpecifier.as`、`group_specifier.rs`）：純資料類別，全部實作：建構子 name 空／null `ArgumentError #2004`；七個旗標預設 false；`minGroupspecVersion` 預設 1（<1 `#2004`）、`maxSupportedGroupspecVersion` 2；`addBootstrapPeer`／`encodeBootstrapPeerIDSpec` 要求 64 個十六進位字元的 peerID（null `#2007`、其他 `#2004`）；`addIPMulticastAddress`／`encodeIPMulticastAddressSpec` 照文件：port 在 `address` 裡（`a:p`，IPv6 要 `[a]:p`）或在 `port` 參數裡，兩邊都有或都沒有 `#2004`，`source` 以 `source@` 前綴；`setPublishPassword`／`setPostingPassword` 存 SHA-256(password + salt) 的十六進位、null 清除；`authorizations()` 是明文密碼的選項、`groupspecWithAuthorizations()` = `groupspecWithoutAuthorizations()` + `authorizations()`、`toString()` 同前者；`makeUnique()` 加 16 個系統亂數位元組。字串版面：`G:` + 十六進位的選項序列，每個選項 = VLU 長度 + 型別 + 內容；Flash 對 `new GroupSpecifier("test")` 的輸出是 `G:0101010c050e74657374`（固定選項 01、0c，名稱選項 0e），這裡完全相同；其他設定的選項型別 Adobe 沒有公開，Timffle 自訂（02～08 旗標、09 版本、0a bootstrap、0b multicast 位址、0f 唯一標記、10／11 密碼雜湊、12／13 授權）並在類別註解標明。
- **`NetGroup`**（`NetGroup.as`、`net_group.rs`）：這個播放器的 NetConnection 永遠不會以 `rtmfp` 連線，建構子照參考文件丟 `ArgumentError`（`#2126`，Flash 用在每個「NetConnection 必須已連線」的檢查）；null 參數 `#2007`、groupspec 不是 `G:` 開頭 `#2004`。其餘 21 個成員宣告成未連線群組的答案（`estimatedMemberCount`／`neighborCount` 0、`localCoverageFrom`／`To` 空字串、`info` 全 0、`receiveMode` 預設 `exact`／`replicationStrategy` 預設 `rarestFirst` 且只接受列舉值 `#2008`、Have／Want 索引超出 0～2^53 `RangeError #2006`、`post()` null、`sendTo*` `NetGroupSendResult.NO_ROUTE`、`addNeighbor`／`addMemberHint` false）；`convertPeerIDToGroupAddress()` 是真的函式（peerID 32 位元組的 SHA-256）。
- **`flash.net.drm`**（`DRMManager.as`、`DRMContentData.as`、`DRMDeviceGroup.as`、`DRMPlaybackTimeWindow.as`、`DRMVoucher.as`、`VoucherAccessInfo.as`、新檔 `AddToDeviceGroupSetting.as`）：沒有 Adobe Access 模組的 Flash——`DRMManager.isSupported` false；`getDRMManager()` 單例、直接 `new` 丟 `ArgumentError #2012`；`networkIdleTimeout` 存放；`authenticate`／`loadVoucher`／`loadPreviewVoucher`／`storeVoucher`／`returnVoucher`／`addToDeviceGroup`／`removeFromDeviceGroup` 先同步檢查參數（null `#2007`、`LoadVoucherSetting` 以外 `#2008`、`returnVoucher` 沒有伺服器或兩個 id 都 null `ArgumentError #2004`——文件），再於下一個計時器 tick 送對應的錯誤事件（`DRMAuthenticationErrorEvent`、`DRMErrorEvent`、`DRMReturnVoucherErrorEvent`、`DRMDeviceGroupErrorEvent`），`errorID` 3344「Missing Flash Access module」、`subErrorID` 0、`drmUpdateNeeded` true、`systemUpdateNeeded` false；`setAuthenticationToken` 存／清每個伺服器＋網域的 token；`resetDRMVouchers()` 無憑證可刪。`DRMContentData()` 不帶位元組可建（四個屬性 null、`getVoucherAccessInfo()` 回一個預設 `VoucherAccessInfo`——文件：至少一個），帶位元組 `IllegalOperationError #2014`（解析由模組負責）。`DRMVoucher`／`DRMPlaybackTimeWindow` 仍是抽象類別（只有模組會建立），getter 讀存放的欄位、`toByteArray()` 回空憑證的位元組；`DRMDeviceGroup` 的 `name` 可讀寫、其餘 null；`AddToDeviceGroupSetting` 三個常數。

## (c) 已知與真 Flash 還不同的地方

| 區域 | 差異 |
|---|---|
| `NetStream.close()` 的事件 | 文件只說停播、時間歸 0；真 Flash 是否在 `close()` 時送 `NetStream.Play.Stop`／`Buffer.Flush` 沒有量到，Timffle 不送。 |
| `NetStream.publish()`／`appendBytes()` 不在資料產生模式 | 在 `connect(null)` 的連線上 `publish()` 真 Flash 報什麼（或丟什麼）沒有文件；文件只說 `appendBytes()` 在非資料產生模式「raises an exception」但沒寫哪一個。Timffle 兩者都不做事、不報。 |
| `NetStream.play2()` 的轉場 | `switch`／`swap`／`append*`／`resume` 在漸進下載上化成 `play(streamName)`；`NetStream.Play.Transition`／`TransitionComplete` 是 FMS 送的，這裡不會出現。 |
| `NetStream.maxPauseBufferTime` 預設值 | 文件沒寫讀取未設定時的值（只說未設定時暫停上限是 60 秒或 2×bufferTime），Timffle 回 0。 |
| `NetStreamInfo` 的每秒速率 | 真 Flash 每類（音訊／視訊／資料）各自量；Timffle 量總下載速率再依已看到的位元組比例分配，每秒取樣一次。 |
| `NetStreamInfo`／`NetStreamMulticastInfo`／`NetGroupInfo.toString()` 的格式 | 文件只說「包含各屬性的值」；`name=value` 空格相連、宣告順序是依 Flash 慣例推定，沒有量到。 |
| `GroupSpecifier` 的選項型別 | 只有固定選項 `01`、`0c` 與名稱 `0e` 與 Flash 相同；旗標、bootstrap、multicast、密碼、唯一標記的型別號與密碼雜湊的確切構造（SHA-256(password+salt)）是 Timffle 自訂。這裡沒有 RTMFP，字串只會被 `NetGroup`／`NetStream` 的建構子拒絕，不會送到任何伺服器。 |
| `NetGroup` 在非 RTMFP 連線上的錯誤碼 | 參考文件只說 `ArgumentError`；Timffle 用 `#2126`。 |
| `DRMManager` 沒有模組時的事件細節 | 錯誤碼 3344 取自 runtime error 清單（「Missing Flash Access module」）；`drmUpdateNeeded` true、`storeVoucher()` 也送 `drmError` 是推定；`DRMContentData(bytes)` 丟 `#2014` 也是推定（文件沒寫建構子的錯誤）。 |
