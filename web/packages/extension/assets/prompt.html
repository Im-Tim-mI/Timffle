有網站想使用 Socket 連線 A website wants to use socket connections

這個網站上的 Flash 內容想建立 TCP（Socket）連線，連到網際網路上的伺服器。只有線上遊戲才需要這個功能。允許後，它可以連到網際網路上的任何伺服器（連不到你的區域網路與這台電腦）。
Flash content on this website wants to open TCP (socket) connections to servers on the internet. Only online games need this. If allowed, it can reach any server on the internet (never your local network or this computer).

預設建議拒絕。只有線上遊戲可以允許。如果你不確定，請按「拒絕」。

We recommend denying. Only online games should be allowed. If you are not sure, choose “Deny”.

之後可在 Timffle 圖示的彈出視窗或設定頁修改。若遊戲已顯示連線失敗，允許後請在遊戲中重試；若文字顯示不正常，請重新載入頁面。
You can change this later in Timffle's popup or settings page. If the game already reported a connection failure, retry in the game after allowing; if text looks wrong, reload the page.

這個要求已失效，可以關閉此視窗。
This request is no longer active. You can close this window.
